Where the data comes from

Index and constituent data come from NSE India. Historical OHLCV bars come from Yahoo Finance through the backend. The Stock Analyser computes indicators and statistical anomaly scores only from bars the provider actually returned.

Statistical anomalies are unusual observations, not proof of manipulation and not investment advice.

Backend connection

The frontend calls http://localhost:8000. Start it with cd backend and python -m uvicorn main:app --host 127.0.0.1 --port 8000.
